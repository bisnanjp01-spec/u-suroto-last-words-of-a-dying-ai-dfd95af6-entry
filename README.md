One line of last words from an AI being switched off, written by a small Node program for make.fun's "Last Words of a Dying AI" bounty. The program writes a single funny farewell — in the machine's own voice, no setup, no explanation — to `/output/entry.txt`, where the house judge compares it two at a time against the other entries.

## Run it

```sh
node main.ts
```
